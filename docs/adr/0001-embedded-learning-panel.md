# 采用网页内常驻学习侧栏

日期：2026-09-26

状态：已接受

## 背景

用户需要隐藏侧栏时保持字幕和翻译，并在进入全屏时自动隐藏、退出全屏后恢复。浏览器原生 sidePanel 的重新打开需要用户手势，不能依赖 fullscreenchange 或 Esc 触发自动打开。关闭侧栏还可能卸载其翻译队列。

## 决定

侧栏改为 YouTube 页面内的扩展 iframe。收起和全屏仅隐藏该 iframe，保留学习会话；手动隐藏状态与全屏状态分开。消息按包含 iframe 的标签页隔离，不随其他标签页激活改变目标。画面字幕的开关由视频页面持有，与侧栏语言模式独立。

## 取舍

保留原生侧栏可以减少网页布局适配，但无法保证用户选择的自动恢复。网页内面板需维护布局、剪贴板授权和标签页隔离，换来可控的隐藏恢复及持续翻译。全屏中主动展开面板会先退出全屏，避免移动 iframe 导致会话重载。
